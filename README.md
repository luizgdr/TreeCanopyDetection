# Tree canopy detection

## Dataset
- Download `train_images.zip` and `train_annotations.json`: [Link](https://solafune.com/competitions/26ff758c-7422-4cd1-bfe0-daecfc40db70?tab=&menu=data)
- Run `setup.py`
- Place `train_annotations.json` under `data`
- Extract .tifs to `data/images/`
- Run `main.py`
